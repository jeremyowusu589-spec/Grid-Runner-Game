# Grid-Runner-Game
🎮 Grid Runner

Grid Runner is a 2.5D obstacle-dodging game built with HTML, CSS, JavaScript, and Three.js.

Controls
* ← / A: Move left
* → / D: Move right
* Space: Restart after Game Over

Features
* 3D graphics
* Random obstacles
* Score tracking
* Collision detection

Built With
* HTML
* CSS
* JavaScript
* Three.js
